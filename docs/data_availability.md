# Data Availability

This public repository is designed for reproducible engineering review without releasing patient-level clinical material.

Released artifacts include code, schemas, safe configuration, synthetic examples, public-source knowledge-base build logic, frozen aggregate manifests and hashes, publication-safe result tables, and publication-safe figure source data.

Not released in the current public version:

- real raw prescription images
- de-identified prescription images
- row-level real annotation JSON files
- row-level reviewer packages
- reviewer identities or free-text review notes
- private state databases, model request dumps, or local service configuration

The release status for real de-identified prescription data and corresponding row-level annotations is `DEFERRED_PENDING_EXPERT_ADJUDICATION`. Future release requires appropriate governance review, independent expert adjudication, and approval for the exact public dataset subset.
