# Reproducibility

## Public Synthetic Smoke Test

```bash
python scripts/run_pipeline.py \
  --input data/examples \
  --annotations-dir data/examples/annotations \
  --config configs/examples/synthetic_pipeline_config.json \
  --output outputs/example_run \
  --resume
```

The same synthetic annotations are mirrored under `data/examples_synthetic/` for public release packaging.

## Dry Run

```bash
python scripts/run_pipeline.py \
  --input data/examples \
  --annotations-dir data/examples/annotations \
  --config configs/examples/synthetic_pipeline_config.json \
  --output outputs/example_run \
  --dry-run
```

## Resource Construction

Private/full-corpus resource construction depends on locally acquired source files and should be run only in an authorized environment:

```bash
python -m src.knowledge.stage2b
python -m src.retrieval.stage2c
python -m src.retrieval.stage2c1
```

## Candidate Ranking, Evidence, And Verification

```bash
python -m src.ranking.stage4
python -m src.evidence.stage5
python -m src.verification.stage6
```

## Final Paper Artifacts

All final aggregate tables, figure source CSVs, rendered figures, claim registries, and writer handoff files regenerate without paid APIs:

```bash
python scripts/reproduce_paper_artifacts.py
```

This command reads frozen aggregate artifacts and precomputed benchmark/audit outputs. It does not regenerate GPT-5.5 annotations or Qwen judgments.

## Benchmark Table Reconstruction

The manuscript-facing benchmark tables are regenerated by:

```bash
python scripts/reproduce_paper_artifacts.py
```

## Final Automated Results Tables

Use frozen aggregate results only. Do not publish patient-level rows.

## Figure Data Generation

Use:

```bash
python scripts/reproduce_paper_artifacts.py
```

Do not regenerate figures from private row-level clinical data in public CI.

## Expert-Validation Metrics

Run only after reviewer files exist in an authorized private environment:

```bash
python rebuild/prepare_stage9_evaluation_package.py
```
